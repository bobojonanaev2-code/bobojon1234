# Интерактивная работа с MySQL в Docker

Практическое задание: запуск MySQL в изолированном контейнере, выполнение SQL-операций, создание дампа базы данных.

## Задание

Источник: [Интерактивная работа с MySQL в изолированном окружении Docker № 1](ссылка_на_методичку)

## Что сделано

- Очищен Docker от старых контейнеров и томов
- Создан `my.cnf` с настройками кодировки `utf8mb4` и логированием
- Запущен контейнер `my-mysql` на образе `mysql:8.0`
- Выполнены SQL-команды:
  - Создание БД `my_database`
  - Создание таблицы `users`
  - Вставка, обновление, удаление данных
  - Удаление таблицы и БД
- Создана тестовая БД `sql_practice` и выполнен дамп в `dump.sql`
- Скопирован лог `general.log` из контейнера
- Проверено управление контейнером (`stop`, `start`, `logs`)
