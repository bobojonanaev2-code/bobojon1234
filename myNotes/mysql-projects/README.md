## 📚 Список практических работ

| № | Практическая работа | Что изучается | Открыть |
|:---:|---|---|:---:|
| **01** | **Основы MySQL и Docker** | Запуск контейнера, базы и таблицы, CRUD, дамп и лог | [📖 Отчёт](mysql-docker-practice/) |
| **02** | **Работа с данными в MySQL** | `SELECT`, `JOIN`, агрегатные функции, подзапросы, восстановление | [📖 Отчёт](mysql-docker-practice-2/) |
| **03** | **Представления (VIEW)** | `CREATE VIEW`, изменение представлений, обновляемость, права доступа | [📖 Отчёт](mysql-view-practice/) |
| **04** | **Операции над множествами** | `UNION`, `EXCEPT`, `INTERSECT`, `CROSS JOIN`, `LEFT JOIN` | [📖 Отчёт](products-mysql/) |
| **05** | **Нормализация данных (3NF)** | Аномалии данных, связи, внешние ключи, перенос и проверка | [📖 Отчёт](mysql-normalization-practice/) |
| **06** | **Алиасы в SQL** | `AS`, псевдонимы таблиц и столбцов, `JOIN`, подзапросы | [📖 Отчёт](mysql-alias-practice/) |

> **Каждая практическая — отдельный проект.** Внутри папки находятся её `README.md` с объяснениями и скриншотами, SQL-дамп и учебные файлы по заданию.
